请处理旧版已保存凭据

检测到旧版在本机磁盘保存的密钥或令牌。为保护凭据，处理前不会发送远程翻译请求。服务选择和地址会保留，本机翻译可以继续使用。

迁移会将旧凭据移入本次浏览器会话内存，并从扩展本机存储删除；若已选择远程服务，将恢复向该服务自动发送完整中文句。下次重启、重载或更新后需重新填写。清除则删除旧凭据，需要时再填。

首次下载中英语言包后，草稿在本机翻译。需要支持 Translator 的桌面 Chrome。

准备 / 验证本机语言包

密钥仅用于本次浏览器会话；浏览器重启、扩展重载、停用或更新后需重新填写。
获取密钥与凭据保护说明

获取火山 AK/SK（需登录）开通和配置说明

进入“API 访问密钥”后选择 Access Key，创建并复制 AK、SK；请勿选择 API Key。登录后若未回到密钥页，可从右上角头像菜单进入“API 访问密钥”。

直接调用火山官方机器翻译接口，无需安装 Python 或启动代理。请使用仅有机器翻译权限的账号密钥。

AK/SK 仅保留在本次浏览器会话内存，不写入扩展磁盘存储、不随 Chrome 账号同步，网页内容脚本不能直接读取。不要共享浏览器配置；本机所有者或调试工具仍可能读取运行中的凭据。

正在使用火山直连时，清除后会切回本机翻译；不会撤销火山账号中的密钥。

保存后，完整中文句会自动发送到下方地址；手动翻译会发送选区或整个草稿。请使用你信任的服务，费用、额度与数据处理方式由该服务决定。

填写完整翻译地址；只填域名时自动补 /api/translate。远程地址须为 HTTPS，本机可用 HTTP。 只填代理的 Bearer 令牌；仅不需要鉴权的接口可留空。令牌仅用于本次会话，浏览器重启、扩展重载、停用或更新后需重填；地址和服务选择保留。
接入要求与令牌保护说明

代理模式的火山 AK/SK 由管理员在服务器配置，不要填入代理访问令牌。令牌仅保留在本次浏览器会话内存，不写入扩展磁盘存储、不随 Chrome 账号同步，网页内容脚本不能直接读取；本机所有者或调试工具仍可能读取运行中的凭据，请勿共享浏览器配置。

清除后保留服务选择；需要鉴权的服务会暂停，请重新填写令牌或切回本机翻译。
