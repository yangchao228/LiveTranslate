LiveTranslate 用户使用说明

Chrome 1.0.8 新增网页自检、按需恢复和双向语言包状态；输入中译英与划词英译中仍独立控制。工具栏“手动翻译”统一正文选区英译中与输入草稿中译英入口。在网页输入中文，预览英文，再由你决定是否替换。插件不会发送聊天消息。默认使用 Chrome 本机翻译，也可以用自己的 AK/SK 直连火山，或选择兼容服务。

1. 安装与更新

Chrome 1.0.8 通过个人站下载与安装页和GitHub Release手动分发，尚未在 Chrome Web Store 上架，没有自动更新。使用桌面 Chrome 138 或更新版本；本机翻译还取决于设备、网络和浏览器策略。当前暂不支持 Edge。

  1. 下载 LiveTranslate-1.0.8.zip，完整解压到长期保留的固定目录。不要直接加载 ZIP，也不要安装后删除该目录。
  2. 打开 chrome://extensions/，开启开发者模式，点击“加载未打包的扩展程序”，选择直接包含 manifest.json 的文件夹。核对扩展版本为 1.0.8。
  3. 在 Chrome 的扩展菜单中固定 LiveTranslate，便于打开工具栏。暂停其他 LiveTranslate 版本，避免两份同时翻译。
  4. 默认本机翻译：打开工具栏 →“准备语言包”→“准备语言包并验证”，保持准备页打开，等到出现实际英文示例和成功提示。工具栏分别显示中译英和英译中状态，在对应方向点击“准备”或“验证”。
  5. 回到 ChatGPT，点击输入框继续写作，无需刷新页面；已有草稿保留，恢复时不会自动翻译旧草稿。其他已打开的普通网页，先聚焦输入框并按 Alt+R（Mac：⌥R）或点击工具栏“手动翻译”，即可按需接入。

从 1.0.3 或更早版本更新：先在旧版工具栏关闭“翻译开关”，等当前译文浮窗消失，再备份原目录，将新版 ZIP 完整解压并覆盖同一固定目录中的文件。在 chrome://extensions/ 找到 LiveTranslate，点击重载并核对版本为 1.0.8，最后打开工具栏重新开启翻译。此顺序用于移除旧版页面监听，无需刷新 ChatGPT，已有输入框草稿保留。

1.0.4 及后续版本再次更新或重载：可保留开启状态，覆盖原目录后重载扩展，回到 ChatGPT 继续写作。其他已打开的普通网页，先点击目标输入框，再按 Alt+R（Mac：⌥R）或使用工具栏手动翻译完成补接。恢复只接入编辑器，不自动翻译或替换已有草稿，也不会发送消息。

同一路径通常保留服务选择和自定义快捷键；换一个目录加载可能创建新扩展实例。重载会清除会话凭据，使用火山或需要令牌的服务时，请打开“翻译设置”重新填写。本机语言包由 Chrome 管理，重载扩展不等于重新下载语言包。

2. 日常使用

  • 自动翻译：中文完整句以 。？！?! 等明确句末标点结束后，等待约 300ms。逗号、分号、冒号和未完成的半句保持安静；纯英文不会自动请求。
  • 手动翻译：按 Alt+R（Mac：⌥R），或点击工具栏中的“手动翻译”。正文选区英译中，输入草稿中译英；按实际目标检查对应开关。正文选区需要开启“划词英译中”，输入草稿需要开启“输入中译英”。在输入框内有选区时只翻译选区；无选区时翻译当前输入框全文，支持无标点、多句和多行。
  • 确认替换：按 Tab 或点击“替换原文”。只替换预览对应的原文，光标放在译文末尾，后续草稿保留，可以直接继续输入。
  • 复制：点“复制”获得预览中的译文，再自行粘贴到目标位置。
  • 输入中译英：Alt+T（Mac：⌥T）或工具栏“输入中译英”开关。关闭后停止自动与手动草稿翻译并清除写作预览，划词英译中仍可使用；重新启用不会自动翻译历史草稿。

没有有效译文时 Tab 保持网页原有功能；插件不接管 Enter 或网页发送快捷键。你修改原句、切换输入框、关闭预览、切换服务后，旧结果会失效，防止替换错内容。

“手动翻译整个草稿”包含输入框里前面的所有句子。截图中的 Hello. 太棒了。 Who are you! 会处理其中的中文。本机提供者保留纯英文句子、空白和换行，翻译含中文的句子；句内已有英文仍可能被模型调整。

快捷键默认只在 Chrome 内生效，“激活该扩展程序”不设默认键。如果与别的扩展冲突或已有自定义设置，以工具栏显示的实际绑定为准；在 chrome://extensions/shortcuts 调整对应行。⌥T 只切换输入中译英，以 Chrome 快捷键设置中的实际命令为准。

网页连接与语言包状态

打开工具栏可检查当前网页是否已接入；显示“重新接入”时，点击即可尝试恢复，无需刷新网页，也不修改已有草稿、焦点或选区。恢复不会自动翻译旧草稿。浏览器内部页、商店、PDF 或网站访问权限限制可能阻止接入；页面变化后请重新检查。“已接入”仅确认主页面连接，不代表所有编辑器、iframe 或翻译服务均可用。

使用 Chrome 本机服务时，中译英和英译中分别显示语言包状态；缺少哪个方向，就在该方向点击“准备”。“已下载”是 Chrome 报告的资源状态，点击“验证”可到准备页运行固定句验证。工具栏检查不会创建或下载模型；切换远程服务后无需准备本机语言包。

网页划词英译中

工具栏提供独立的“划词英译中”开关，默认开启。关闭后不再显示正文翻译入口，工具栏“手动翻译”和快捷键也不能翻译正文；输入中译英仍可使用。“输入中译英”与“划词英译中”各自独立控制，关闭其中一项不会暂停另一项；两项均关闭时停止全部翻译。

在普通网页正文选中英文单词、句子或短段落，点击选区旁带句隙标志的“翻译成中文”按钮、工具栏“手动翻译”，或使用工具栏显示的手动翻译快捷键。这三个入口使用同一正文英译中能力；仅选中文字只显示入口，不发起翻译。

阅读浮窗仅展示中文译文，保留复制和关闭按钮，按 Esc 也可关闭；失败时可重试或准备英译中。不会替换网页正文，也不拦截 Tab。最多选中 5,000 个 UTF-16 单元（JavaScript 字符串长度）；含汉字、编辑器、扩展界面、隐藏内容或跨编辑器的选区不提供入口。输入框仍保留中文输入译英文的默认行为。

本机英译中首次使用请打开准备英译中，点击按钮下载并验证该方向语言包。默认中译英准备入口保留。使用已授权远程服务时，点击翻译后会把所选英文发送至当前服务；服务失败不自动换服务。

兼容性尚未覆盖所有网站、PDF、浏览器内部页面和首次语言包下载路径。已打开的普通网页可先在工具栏检查并点击“重新接入”，或选中英文后使用手动翻译快捷键补接。

3. 选择翻译服务

工具栏 → 翻译设置。选项和输入地址需要点击“保存”后才生效。切换立即关闭旧译文，下次翻译使用新选择；不会自动转用其他服务。

4. 用自己的 AK/SK 直连火山引擎

直接打开火山控制台，获取 AK/SK（需要登录）。如果内置浏览器打不开，请复制链接到 Chrome 地址栏打开。

  1. 登录后，在“API 访问密钥”页面选择 Access Key 并创建密钥，获取 Access Key ID（AK）和Secret Access Key（SK）。插件需要这两个值，请勿选择 API Key。若登录后未回到密钥页，再打开上面的链接，或从控制台右上角头像菜单进入“API 访问密钥”。
  2. 确认该账号已开通机器翻译服务、额度可用；使用 IAM 用户时，需具有机器翻译所需权限，建议使用仅有这些权限的用户密钥。
  3. 打开插件工具栏 →“翻译设置”→“火山引擎（自带 AK/SK 直连）”。
  4. 在两个密码字段中填写 AK、SK。无需填写接口地址、区域或代理令牌，也无需启动 Python。
  5. 点击“保存并授权此服务”。插件仅申请 https://translate.volcengineapi.com/* 的访问权限；拒绝时保留原来的服务设置。
  6. 点击“测试已保存服务”，发送固定句“你好，今天测试翻译服务。”。看到成功提示与英文译文后，返回网页使用。

扩展后台完成火山要求的签名。请求固定发往官方文本翻译接口，AK 作为身份标识包含在签名头中，SK 用于本机计算签名，不发送给火山或任何代理。正式调用会使用你的账号额度；当前扩展不提供共享账号。

AK/SK 仅保存在本次浏览器会话的内存存储，不随 Chrome 账号同步。浏览器重启或扩展禁用、重载、更新后需要重新填写；扩展后台休眠不影响本次会话。网页及内容脚本不能直接读取密钥，设置页和后台可以读取；这不抵御拥有电脑或扩展调试权限的人。不要把密钥放进截图、反馈或聊天中。旧版持久化凭据会提示你迁移到本会话或清除；处理前不发远程翻译。

要停用直连，选“Chrome 本机翻译”并保存；密钥保留供下次使用。要删除密钥，在火山直连设置中点击“清除本次会话的火山密钥”：若当前使用直连，会自动切回本机。清除插件保存的副本不会吊销火山账号上的密钥，需要吊销时到火山控制台处理。

当前直连单次限制 5,000 个 JavaScript 字符单元，按官方上限保守校验；更长草稿请缩小选区。不会自动拆成多次收费请求。15 秒超时或服务错误时保持原文，不自动换服务。鉴权失败请检查复制内容、机器翻译权限和电脑时间；额度问题请查看火山账号。

依据：火山文本翻译 API。直连功能已做官方 SDK 签名对照和使用虚构密钥的真实扩展回归；每位用户仍需用自己的账号完成上述固定句测试。

已有旧版火山代理配置

升级会保留旧地址和当前选择；如果检测到旧版 local 凭据，先在设置页明确选择“移入本次会话并删除旧保存”或“清除旧凭据”，处理前暂停所有远程请求。随后可继续旧代理，或选直连、为本次会话填 AK/SK 并保存。新用户如需使用管理员提供的代理，选择“自定义兼容翻译服务”，填写完整代理地址及可选 Bearer 令牌；不要把火山 AK/SK 填入代理令牌栏。

自行运行仓库 Python 代理仍是可选方式：在源码目录创建 .venv、安装 requirements.txt，通过自己的密钥管理方式注入 VOLCENGINE_ACCESS_KEY / VOLCENGINE_SECRET_KEY（可选 TRANSLATION_PROXY_TOKEN），再运行 ./start_local.sh。自定义地址填 http://127.0.0.1:8000/api/translate。此地址指向使用者自己的电脑，不能让别人访问到你的电脑。完整代理说明见源码 docs/service-integration.md；本机 Flask 启动方式不作为公网托管方案。

5. 接入自己的翻译服务

选择“自定义兼容翻译服务”，填写完整接口 URL。远程要求 HTTPS，本机允许 http://127.0.0.1 或 http://localhost。只填域名时自动补 /api/translate。地址不能包含用户名、密码、查询参数、片段，也不能重定向。

请求方式：POST，Content-Type: application/json。填写令牌后添加 Authorization: Bearer <你的代理令牌>。不会附带网页 Cookie。

{ "text": "你好。", "sourceLang": "zh", "targetLang": "en" }

成功返回 HTTP 200 和如下 JSON，translatedText 必须是非空字符串：

{ "translatedText": "Hello.", "detectedSourceLanguage": "zh" }

可以在服务端调用自己选择的模型、厂商或本机引擎，再把返回值转换成这个结构。OpenAI 兼容的聊天接口、其他原始签名接口等不能仅填 URL 就直接使用，需要服务端适配请求和响应；火山用户优先选择内置的 AK/SK 直连选项；当前不提供浏览器内运行任意脚本、远程插件或自定义请求模板。

自定义兼容服务请求 15 秒超时，最多 100,000 个 JavaScript 字符单元；供应商可能有更低限制。失败保持草稿，缩小选区或修改服务后手动重试。具体接口规范与适配示例位于源码的 docs/service-integration.md。

6. 数据、权限与费用

  • 本机模式不调用远程翻译服务；语言包由 Chrome 下载与管理，大小和可用性取决于浏览器，扩展 ZIP 不包含模型。
  • 保存并选择远程服务后，输入中译英开启时，后续输入的完整中文句会自动持续发送至该服务；手动翻译发送所选文本，无选区时发送整个草稿。正文划词须点击翻译入口或使用手动翻译快捷键才发送所选英文。仅使用你信任的服务，查明供应商与代理的保存政策。
  • 服务选择和接口地址保存在本机 local 存储；AK/SK 和可选代理令牌仅存本会话 session 内存，重启或扩展禁用、重载、更新后需重填，都不随 Chrome 账号同步。旧版持久化凭据需明确迁移或清除。
  • 输入中译英和划词英译中两个独立布尔开关可能通过 Chrome 同步；译文缓存只存在页面内存，不建立云端翻译历史。
  • 内容脚本需要读取/更改可访问网页中的输入框，因此安装可能显示网站数据权限提示。1.0.4 新增的固定主机权限仅为 https://chatgpt.com/*，用于安装、更新、重载及浏览器启动后恢复已打开的 ChatGPT 主页面；其他普通网页通过工具栏或手动快捷键的当前标签授权按需恢复。此权限不把草稿发送到 ChatGPT 或项目方；替换仍由你确认，不自动发送聊天内容。
  • 仓库代理当前代码不主动打印草稿、译文或授权头；网络服务、供应商及自行添加的日志需由管理员另行确认。

7. 常见问题

现象检查与处理
没有自动翻译检查开关、当前服务和输入法是否已确认；逗号/半句/纯英文不会自动翻译。更新到 1.0.4 后，ChatGPT 可无刷新恢复；从旧版首次更新需先暂停再更新。其他旧页面先聚焦输入框并用 Alt+R（Mac：⌥R）或工具栏手动翻译补接。粘贴的整段提示词建议用手动入口。
语言包不可用或准备失败检查桌面 Chrome 版本、下载网络和管理策略；关闭其他正在使用翻译的页面后重试。准备页支持取消当前操作，Chrome 已开始的下载可能仍在后台继续。
提示需要用户操作先在准备页完成验证，再返回网页点击输入框并立即按手动快捷键。不同网页可能再次要求操作，不一定需要再次下载。
模型初始化/翻译超时语言包持续下载时继续等待；无进展 120 秒或总计 10 分钟后提示重试。准备页验证和本机单次翻译各限 30 秒。缩小选区并重试；不会自动向云端发送。
远程连接失败检查保存的 URL、服务进程、权限、HTTPS 证书和网络；禁止重定向，直接填写最终接口地址。代理要返回约定 JSON。
火山鉴权失败检查 AK/SK、机器翻译权限和系统时间；确认服务已开通。测试页不回显原始供应商敏感错误。
代理 HTTP 401 / 403检查代理访问令牌与授权，不要把火山 AK/SK 填到代理令牌栏。
HTTP 429 或 5xx联系服务管理员检查额度、限速、供应商状态和服务器配置；原文保持不变。
切换服务后旧译文消失这是预期行为。再次手动翻译即可获取新服务的结果。
快捷键无效查看工具栏的实际键位和 Chrome 快捷键设置；先点击目标编辑器。某些网页/系统或其他扩展可能占用快捷键。
部分页面不能使用Chrome 内部页、受限制的页面、非安全上下文或 iframe 权限策略可能阻止 API。复杂编辑器未保证全部兼容；富文本替换按纯文本处理，不保证保留字体等内联格式。

8. 切回本机、重置与卸载

在设置页选择 Chrome 本机翻译并保存，即停止后续远程翻译。已保存的远程配置保留，方便下次切换；直连密钥用“清除本次会话的火山密钥”删除。要删除代理令牌，使用设置页的“清除这个服务的会话令牌”按钮；也可以在对应服务中清空并保存。已有主机授权不会因切回本机而自动撤销，可在 Chrome 扩展详情中管理网站访问权限。卸载扩展会移除该扩展的本机配置；Chrome 可能保留它统一管理的语言包。
