需要桌面 Chrome 138 或更新版本，首次下载时请保持本页打开。失败时可检查网络或浏览器策略后重试，不会自动切换云端。翻译结果仍需你确认。

准备好后，这样开始

  1. 回到网页，点击输入框，输入完整中文句子。
  2. 无句号或整段草稿可用 Alt/⌥+R 手动翻译，Tab 替换原文。
  3. Alt/⌥+T 启停；快捷键若冲突，可在扩展工具栏中调整。

本机模式无需申请密钥、安装 Python 或运行翻译服务。
