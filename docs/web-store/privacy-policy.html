隐私政策

更新：2026-10-18 · 对应 LiveTranslate Chrome 1.0.8

Chrome 1.0.8 通过个人站与 GitHub Release 手动分发，尚未在 Chrome Web Store 上架。此版新增当前网页连接检查、按需恢复和双向语言包状态；输入中译英与划词英译中继续独立控制。两项布尔开关可通过 Chrome 同步；权限、默认输入中译英和会话凭据规则保持不变。

LiveTranslate 提供网页输入框中的中译英写作与正文划词英译中阅读。它读取正在编辑的内容，生成英文预览，并由你决定复制或替换。它不会替你发送消息、提交评论或提交网页表单。

1. 处理哪些内容，为什么处理

输入中译英开启后，会在 Chrome 允许访问的网页和嵌入框架中发现受支持的普通文本框、搜索框、textarea 和富文本编辑器。为判断本次编辑的句子、选区及替换前后文，它在挂接编辑器和处理输入事件时读取编辑器的全文到当前页面内存，包括可能已经存在的草稿；这不限于你刚输入的几个字。

  • 自动翻译：处理本次编辑涉及的完整中文候选句，约短暂合并后请求翻译。未完成句、纯英文和句内逗号等通常不触发；它不会为自动翻译扫描重译全部历史句子。
  • 手动翻译：有选区时处理选区；无选区时处理当前编辑器的整个草稿，可能包括英文、中文、多句和多行。
  • 网页划词：在页面内读取正文英文选区和节点范围，显示翻译入口。仅选中文字不发起翻译；你点击入口或使用手动命令后，才将最多 5,000 个 UTF-16 单元（JavaScript 字符串长度）的所选英文交给当前翻译服务。阅读浮窗仅显示中文，提供复制和关闭，不替换网页正文、不接管 Tab。关闭工具栏“划词英译中”后，选区按钮、工具栏手动入口与快捷键均不再翻译正文；输入中译英由单独的“输入中译英”开关控制，两者互不暂停。
  • 原文快照、前文、选区和编辑事件：用于确认结果仍与草稿匹配、避免旧结果替换新内容、处理输入法状态、恢复光标和提供 Tab 替换。它不建立键盘输入日志或行为分析档案。
  • 复制与替换：你点击复制时，扩展将译文写入系统剪贴板，不读取剪贴板历史；你确认替换时，它修改所选编辑器中仍匹配的范围。网页本身可以看到编辑器及页面上的译文界面，系统和网页可能按各自规则保留内容。

1.0.4 新增的固定主机访问权限仅为 https://chatgpt.com/*，用于在安装、更新、重载及浏览器启动后重新接入已打开的 ChatGPT 主页面。其他普通网页只在你使用工具栏或手动快捷键、Chrome 授予当前标签访问权后按需恢复。恢复过程重新读取编辑器内容到当前页面内存，但不写入草稿、不改变焦点或选区、不自动翻译已有草稿，也不发送聊天消息。这项权限不改变下述本机与远程服务的数据去向。

工具栏网页检查只向当前主页面查询扩展连接状态，不读取或上传草稿；点击“重新接入”时复核当前标签与导航状态后按需恢复，恢复过程遵循上述页面内存读取规则。中译英和英译中状态通过 Chrome 的 availability 分别读取，工具栏不会创建或下载模型。“已下载”表示浏览器报告的资源状态，不代表固定句验证已经通过；点击对应方向的准备或验证按钮后，准备页才按你的操作下载并翻译固定测试句。

标准密码输入框、只读和禁用的输入框不属于支持范围。但普通文本框中的个人信息、邮件草稿、工作秘密、健康或财务内容无法自动识别。请关闭不希望处理的对应场景；两项开关都关闭才会停止全部翻译。

2. 默认 Chrome 本机翻译

普通分发版新安装默认使用 Chrome Translator API。待译文本在本机处理，LiveTranslate 不将这些翻译请求发送给项目方或远程翻译接口，也不会在本机失败时自动改用云服务。

首次准备可能由 Chrome 联网下载语言包，需要你的操作、合适设备、网络及浏览器环境。Chrome 的下载、账号同步和其他浏览器行为由 Chrome 自身控制；本政策不承诺整个浏览器完全离线或从不联网。语言包由 Chrome 管理，与扩展的草稿缓存不同。

3. 主动选择远程服务后的持续发送

你可在设置中选择火山引擎直连、自定义兼容服务，或继续使用旧版已保存的代理配置。保存前，设置页说明接收方、费用和发送行为，并申请具体服务主机权限。

选定并保存远程服务后，输入中译英开启期间，后续输入触发的完整中文候选句会自动发送到该服务，直到你关闭输入中译英或切回本机；每句不再逐次确认发送。手动翻译会发送所选文字或整个草稿。网页正文划词在你点击翻译入口或使用手动命令后发送所选英文，源语言为 en、目标语言为 zh。设置页的“测试已保存服务”发送固定测试句，不发送当前网页草稿。

  • 火山直连：待译文本、源语言和目标语言发往火山官方 translate.volcengineapi.com。AK 用于标识你的账号；SK 参与本机签名计算，不随翻译请求发送，签名及必要认证参数会发送给火山。服务方也可能看到正常连接所需的 IP 地址及请求元数据。
  • 自定义或旧代理：待译文本、源语言、目标语言发送给你保存并授权的完整服务地址；配置 Bearer 令牌时，通过请求头发给该服务用于认证。服务可能再将内容转发给其上游供应商，应由该服务提供者说明。

扩展的远程请求使用 HTTPS；仅同一电脑的 localhost / 127.0.0.1 服务允许 HTTP。扩展不附带浏览器 Cookie，不跟随服务重定向。服务出错时保持原选择，不自动改用另一服务。切换服务会使旧预览、缓存和响应失效，但已发出的请求不能从接收方收回。

火山及你指定的服务按照各自协议、账号设置和隐私规则处理数据。LiveTranslate 无法替这些服务保证不记录日志、不用于训练、固定保留期限或删除已收到的文本；请在使用前核对接收方规则。费用与额度由你的服务账号或服务提供者承担、计算。

4. 设置、凭据和存储

  • chrome.storage.local：保存服务选择、配置版本、服务地址、服务是否需要令牌的标记、旧版兼容配置及悬浮窗偏移等非秘密设置，不通过 LiveTranslate 的 Chrome 账号同步存储传输。
  • chrome.storage.session：AK/SK 和代理 Bearer 令牌只保存于当前扩展会话的内存。Chrome 重启、扩展重载、禁用或更新会清除这些凭据；服务选择和地址仍保留，需要认证的服务须重新填写凭据才能继续。扩展不会因令牌过期或被清除就静默改为匿名请求；确实无需鉴权的服务可继续使用。
  • chrome.storage.sync：只保存输入中译英开关（enabled）、划词英译中开关（readingEnabled）及更新时间。两项开关独立，关闭其中一项不会关闭另一项。你启用 Chrome 同步时，Chrome 可在你的浏览器间同步这些设置；未同步时按 Chrome 的本地行为保存。草稿、译文和服务密钥不写入 sync。
  • local 和 session 的访问限定为扩展可信页面和后台；设置读取、保存、清除及固定句测试只接受扩展设置页消息，内容脚本只能取得服务类型和配置版本。TRUSTED_CONTEXTS 访问隔离不等同于磁盘加密，也不能抵御设备所有者、扩展调试环境或已被控制的浏览器访问内存。

旧版安装曾把明文秘密保存在 local。新版本检测到后，会暂停所有远程翻译并提示你选择“移入本次会话并删除旧保存”或“清除旧凭据”；它不会回显或静默使用旧秘密，也不在未告知你时丢弃配置。迁移先写入 session，成功后删除 local 中的秘密字段；清除会移除旧秘密和当前会话秘密，保留非秘密选择和地址。处理前，旧秘密仍留在本机，直至你明确处理或卸载；删除不是对设备备份、历史文件或供应商密钥的安全擦除保证。

切回本机后，非秘密服务配置、当前会话凭据和已授予权限保留，以便在会话有效期间再次选择。请勿共享浏览器配置或调试访问，勿将密钥、令牌或含敏感草稿的截图发给支持人员。

5. 内存缓存与保留时间

原文快照、原文参与的缓存键、译文及正在进行的任务保存在当前网页内容脚本内存，用于去重、预览和替换。它们不作为翻译历史写入 local / sync，也不发送到项目方统计系统。缓存没有固定时间到期机制；切换翻译服务会清空翻译缓存，刷新或关闭该页面会释放该页面的扩展运行状态。

关闭对应开关会移除该场景的入口、任务和浮窗，并阻止其旧响应展示；关闭输入不影响阅读，关闭阅读不影响输入；当前实现不会立即清空该页面的全部翻译缓存。若需清理页面内扩展状态，请在停用后刷新或关闭相关页面。浏览器进程、操作系统内存及网页本身的保留行为不在扩展完全控制范围内。

6. 如何控制和删除

  • 停止处理：分别关闭工具栏“输入中译英”和“划词英译中”可停止对应场景，两项均关闭可停止全部翻译；切回本机并保存可停止后续远程翻译。单纯关闭浮窗不会切换服务或撤回已发送请求。
  • 火山密钥：设置页“清除本次会话的火山密钥”会清空本扩展会话中的 AK/SK；当前若使用直连，会切回本机并使旧结果失效。该操作不会撤销供应商账号中的真实密钥。
  • 代理令牌：选择相应服务并点击“清除这个服务的会话令牌”，会保留服务选择；原来要求令牌的服务会暂停，重新填写后才能继续。只有服务确实无需鉴权时，才将令牌留空并重新保存，以明确改为无鉴权接口。
  • 旧保存处理：用“移入本次会话并删除旧保存”或“清除旧凭据”处理提示中的旧版 local 秘密。后者同时清除当前会话秘密，保留服务选择和地址；清除不等于切回本机或撤销供应商密钥。
  • 主机授权：清除凭据或切回本机不会自动撤销已授予的主机权限。可在 Chrome 的扩展详情管理网站访问授权；撤销后，扩展会在再次请求时提示重新授权。
  • 全部扩展本机数据：卸载扩展会清除 Chrome 为该扩展保存的本机存储。清理浏览历史不等于清除扩展设置；卸载不会删除 Chrome 自行管理的语言模型、供应商数据或网页保存的草稿。
  • 供应商数据或密钥撤销：需在相应服务方账号或支持渠道处理。扩展没有权限代你执行供应商账号删除、撤销或数据清理。

7. 项目方的数据使用边界

当前扩展没有广告、分析 SDK 或开发者遥测接口；项目方不通过扩展收集草稿、译文或浏览历史，不出售这些数据，不用于广告定向、信用评估或与翻译写作无关的用途，也不设供人员查看用户草稿的后台。

LiveTranslate 对通过 Chrome API 和网页编辑器取得的信息的使用遵守 Chrome Web Store 用户数据政策及 Limited Use 要求，限于提供所披露的中译英写作与划词英译中阅读能力。只有你选择远程翻译时，才为该用途向相应服务传输待译内容及必要认证信息。项目方不例行人工阅读草稿；如你主动提交某段排障资料，发布者只能在你明确同意的范围内使用它。

本政策和支持页面文件不包含分析脚本、第三方字体、外部媒体或表单。公开页面由 Vercel 托管，域名同时使用 Cloudflare 网络分发服务；Cloudflare 和 Vercel 为连接交付处理 IP、访问时间、请求路径等必要元数据。该域名当前响应头启用网络错误报告，支持的浏览器可能按响应头向 Cloudflare 发送网络错误诊断。具体日志及报告的保留方式和期限尚未核实，本政策不承诺页面访问无日志或固定保留期限。
