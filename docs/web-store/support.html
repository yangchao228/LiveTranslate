使用与支持

Chrome 1.0.9 补齐输入中译英、划词英译中和手动翻译三个快捷键；保留当前网页连接检查、按需恢复和双向语言包状态；打开工具栏即可查看连接，需要时点击“重新接入”。输入中译英与划词英译中仍独立控制，精简中文阅读浮窗和品牌翻译按钮保留。工具栏“手动翻译”：正文选区英译中，输入草稿中译英。输入中译英默认行为保留。

更新：2026-10-19 · Chrome 1.0.9 使用说明

LiveTranslate 当前通过个人站和 GitHub Release 手动分发 Chrome 1.0.9，尚未在 Chrome Web Store 上架，暂不支持 Edge。本页提供使用、排障和联系入口；兼容性与服务状态请以实际操作结果为准。

第一次使用

  1. 从个人站下载与安装页获取 LiveTranslate-1.0.9.zip，完整解压到长期保留的固定目录；打开 chrome://extensions/，开启开发者模式，点击“加载未打包的扩展程序”，选择直接包含 manifest.json 的文件夹。固定工具栏图标，核对版本为 1.0.9。不要在安装后删除解压目录。当前没有商店安装和自动更新。
  2. 使用支持 Translator 的桌面 Chrome 138 或更新版本。工具栏分别显示中译英和英译中语言包状态；在需要的方向点击“准备”，再于准备页点击按钮并保持网络，等待实际固定句验证成功。已下载时可点击对应“验证”复核。
  3. 回到 ChatGPT，点击输入框即可继续，无需刷新；恢复时保留已有草稿且不自动翻译旧草稿。其他已打开的普通网页，先点击输入框并按 Alt+R（Mac：⌥R）或用工具栏手动翻译补接。输入“今天我想练习英文写作。”可测试自动翻译。查看译文后，选择“复制译文”，或在支持的编辑器中按 Tab / 点击“替换原文”。
  4. 需要翻译输入框里的粘贴内容时，选中文字后点击工具栏“手动翻译”或使用手动快捷键；无选区时翻译整个草稿。扩展不会代你发送内容。

默认 Alt+T（⌥T）切换输入中译英、Alt+Y（⌥Y）切换划词英译中、Alt+R（⌥R）手动翻译。更新保留已有绑定；在 chrome://extensions/shortcuts 检查三个对应命令，“激活该扩展程序”留空。若旧版把 ⌥R 绑在激活行，先清空，再绑定到“手动翻译选区或整个草稿”。

如何更新到 1.0.9？

从 1.0.3 或更早版本更新：先在旧版工具栏关闭“翻译开关”，等译文浮窗消失；备份原目录，将新版 ZIP 完整解压并覆盖同一固定目录中的文件。在 chrome://extensions/ 找到 LiveTranslate，点击重载，核对版本为 1.0.9，再打开工具栏重新开启翻译。无需刷新 ChatGPT，已有草稿保留。

从 1.0.4 开始的后续更新或重载：可保留开启状态，覆盖原目录后重载扩展。ChatGPT 已打开的主页面会自动恢复接入；其他普通页先聚焦输入框并按 Alt+R（Mac：⌥R）或点击工具栏“手动翻译”。恢复不改写草稿、焦点或选区，也不会自动替换或发送。若 Chrome 收回或限制了网站访问权限，请先在扩展详情检查授权。

同一路径通常保留服务选择和快捷键；换目录加载可能创建新扩展实例。个人站与GitHub Release提供相同 ZIP 和 SHA-256 校验文件。

重载会清除会话凭据。使用火山或需要令牌的服务时，打开工具栏“翻译设置”重新填写并保存；本机模式无需填写密钥。当前版本通过个人站手动更新，没有商店自动更新。

如何使用网页划词英译中？

在普通网页正文选中英文单词、句子或短段落，点击旁边带句隙标志的“翻译成中文”按钮、工具栏“手动翻译”，或按工具栏显示的手动翻译快捷键（默认 Alt+R，Mac 为 ⌥R）。仅选中文字只显示入口，不请求翻译。选区需含拉丁字母、无汉字，最多 5,000 个 UTF-16 单元（JavaScript 字符串长度）；输入框、隐藏内容和跨编辑器选区不提供此入口。

阅读浮窗仅显示中文译文，保留复制与关闭按钮，按 Esc 也可关闭；不会替换网页正文，也不拦截 Tab。Chrome 本机模式首次使用时，在工具栏英译中方向点击“准备”，再点击准备页按钮下载并实际验证 en→zh 语言包；中译英状态和入口独立保留。已打开的普通阅读页，可先在工具栏检查连接并点击“重新接入”，或选中英文后按手动快捷键补接。浏览器内部页、商店、PDF 和部分嵌入页可能不可用，兼容性以实际结果为准。

如果选用了远程服务，点击翻译入口或按手动命令后，所选英文会发送至当前已授权服务；失败不自动换服务。划词浮窗不会改变输入框中译英的默认行为。

工具栏“划词英译中”默认开启。关闭后不显示正文翻译按钮，工具栏手动入口和快捷键也不再翻译正文；输入中译英仍可使用。“输入中译英”和“划词英译中”各自独立控制，关闭其中一项不会暂停另一项；两项均关闭时停止全部翻译。手动翻译按正文选区或输入草稿检查对应开关。翻译失败时保留重试或准备英译中入口。

如何检查网页连接和语言包？

打开工具栏自动检查当前主页面；“已接入”只确认主页面连接，不代表所有编辑器、嵌入框架或翻译服务可用。需要时点击“重新接入”，不会刷新网页、改写草稿、改变焦点或选区，也不会自动翻译旧草稿。内部页、商店、PDF 或网站访问限制可能阻止接入；页面变化后可重新检查。

本机服务分别显示中译英、英译中状态；“已下载”是 Chrome 报告的资源状态，可点击对应“验证”进入准备页实际翻译固定句。工具栏只读状态，不创建或下载模型。切换远程服务后无需准备本机语言包。

为什么没有自动翻译？

先确认工具栏“输入中译英”已开启、光标在可编辑输入框中、输入法已经确认。自动模式等待完整中文句末；逗号、分号、冒号、纯英文和未完成句保持安静。网址、邮箱和小数中的句点会保守处理。对粘贴草稿、没有明确句末或特殊编辑器，请使用工具栏手动翻译或 Alt+R（Mac ⌥R）。

Chrome 内部页面、商店页面和某些嵌入页面不能正常注入或调用本机翻译。1.0.4 仅为 https://chatgpt.com/* 主页面新增固定访问权限，以便安装、更新或重载后自动接入；其他普通页需通过当前标签的工具栏或手动命令按需接入。首次从旧版更新请先暂停旧版再重载。不要同时在同一页面启用两个 LiveTranslate 版本。

语言包下载失败、取消或超时怎么办？

在准备页查看失败原因，检查网络、Chrome 版本、设备策略及可用资源后重试。可以取消准备；取消后旧任务不应继续显示成功结果。翻译失败不自动切换到远程服务。不同站点首次调用可能再次需要你的点击或快捷键操作，这不必然表示重新下载了模型。

本机模式有浏览器、设备和网络限制；最低版本不保证每台设备或每个页面都可用。官方能力条件见Chrome Translator API。

Tab 没有替换，或页面拒绝替换怎么办？

只有仍匹配当前草稿的有效译文才可替换。加载、错误、旧结果或已修改原文时，Tab 保留正常网页行为。复杂受控富文本编辑器可能拒绝写回；出现失败提示时，先检查原草稿，使用复制退路。不要反复触发不可靠的替换。复制后在目标位置正常粘贴，并检查前后文。

富文本按纯文本处理，不保证保留链接、加粗等格式，也不保证所有网站都兼容。没有验收记录支持时，不把某个真实站点视为已兼容。

快捷键不生效怎么办？

默认 Alt+T 只切换输入中译英、Alt+R 手动翻译，Mac 为 ⌥T / ⌥R。从工具栏展开“快捷键与操作提示”查看实际绑定。打开 chrome://extensions/shortcuts，检查冲突或未分配的命令；Chrome 可能保留你以前的设置。“激活该扩展程序”会打开工具栏弹窗，与两个命令不同。多个编辑框不明确时先聚焦目标输入框。

火山直连和自定义服务如何收费？

当前扩展没有内购或订阅流程；本机翻译没有云 API 调用费，首次语言包下载消耗网络。火山直连使用你自己的账号、AK/SK、开通状态和额度，可能产生供应商费用。自定义服务按提供者的价格及限制执行，扩展不提供额度或费用保证。

在扩展设置中选择服务，阅读数据说明，填写自己的配置并保存授权，然后使用固定句测试。不要向支持人员发送密钥。火山直连单次最多 5,000 个 UTF-16 单元，远程请求超时为 15 秒；超限缩小选区。401 / 403 检查账号授权和令牌；429 检查额度、频率和服务状态。

选择远程且输入中译英开启时，完整中文候选句会随输入自动发给该服务；手动入口发送选区或整个草稿；正文划词在点击翻译入口或使用手动命令后发送所选英文（en→zh）。不希望继续发送时，分别关闭对应场景开关（两项均关闭可停止全部翻译），或切回本机并保存。已发送的内容无法撤回；供应商保留规则见对应服务。详见隐私政策。

如何清除配置和停止访问？

AK/SK 和 Bearer 令牌只在 Chrome 扩展当前会话内存保存。浏览器重启、扩展重载、禁用或更新后会清除，需要认证的服务需重填，服务选择和地址保留。关闭工具栏两项翻译开关不会清除会话凭据；在 Chrome 扩展管理页禁用整个扩展会清除会话凭据。

“清除本次会话的火山密钥”只清除扩展会话中的 AK/SK，不撤销供应商密钥；当前使用直连时会切回本机。“清除这个服务的会话令牌”会保留服务选择，需要令牌的服务会暂停，扩展不会改成匿名发送。仅当服务确实无需鉴权时，才把令牌留空重新保存，明确改为无鉴权接口。

旧版 local 凭据会提示“移入本次会话并删除旧保存”或“清除旧凭据”；处理前暂停所有远程翻译。旧秘密不会回显或静默使用，也不会在你处理前自动删除；迁移后下次重启仍需重新填写。清除旧凭据还会清除当前会话秘密，保留非秘密服务选择和地址。

切回本机保留当前会话中尚未失效的凭据、普通配置和主机授权；Chrome 扩展详情可管理网站访问权限。停用后刷新/关闭网页可清理页面内扩展状态，卸载可清除本机扩展存储。Chrome 语言包和服务方记录需按对应方规则处理。
